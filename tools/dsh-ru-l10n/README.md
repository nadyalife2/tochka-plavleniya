# Русификация плагина `dsh-deepseek-web-login`

Плагин веб-входа DeepSeek рисует панель настроек на китайском: подписи зашиты
прямо в `lib/client.js`. Этот инструмент переводит **ключевые экраны** —
аккаунты, вход, статус, ограничение запросов, транспорт, журнал вызовов, —
не трогая логику плагина.

## Что переводится

| Экран | Что видно по-русски |
|---|---|
| Аккаунты | «Новая группа», «Войти заново», «Переключить», «Заметка», «Убрать», статусы «✅ Текущий» / «❌ Нужен повторный вход» |
| Вход | шаги входа, «Данные входа захвачены и сохранены», ручная вставка Token, проверка связи |
| Статус | «Время захвата», «Источник данных входа», «Заголовки отпечатка», «Проверка сервера» |
| Ограничение запросов | «Ограничение запросов», параллельность, очистка сессий, автовход, пределы интервалов |
| Транспорт | «Транспорт (отпечаток)», «Сетевой стек Chrome (рекомендуется)», режим передачи контекста |
| Журнал | «Журнал вызовов», «Количество вызовов», «Расход по дням», «По аккаунтам» |
| Данные и версия | «Расположение данных», «Экспорт бэкапа», «Проверить обновления» |

Всего в словаре 125 записей (164 вхождения в коде).

**Не переводится намеренно:** остальные ~300 подписей (редкие подсказки, диагностика
встроенного браузера, часть текстов «洗白»/UA), а также все комментарии кода —
они не влияют на работу и их перевод усложнил бы обновления.

## Как применить

```powershell
python tools/dsh-ru-l10n/patch_plugin_ru.py --check   # посмотреть, что изменится
python tools/dsh-ru-l10n/patch_plugin_ru.py           # применить
```

После применения **перезапустите DSH** — подписи читаются при старте плагина.

## Как откатить

```powershell
python tools/dsh-ru-l10n/patch_plugin_ru.py --revert
```

Оригинал сохраняется рядом: `lib/client.js.zh-backup`.

## Важно: обновление плагина

`node_modules` перезаписывается при `npm update` / `dsh plugin add`, поэтому
после каждого обновления плагина скрипт нужно запустить снова. Проверить,
не сломалась ли версия:

```powershell
python tools/dsh-ru-l10n/patch_plugin_ru.py --check
```

Команда покажет, сколько записей словаря нашлось в текущей версии. Если почти
ничего не находится — плагин сильно изменился, словарь нужно актуализировать.

## Гарантии безопасности

Скрипт заменяет только **полные строковые литералы** вида `"текст"` и пропускает:

- литералы с подстановкой `${...}` (шаблонные строки);
- литералы, участвующие в сравнениях и селекторах (`=== "x"`, `includes("x")`, `case "x"`).

Перед записью создаётся резервная копия, после применения проверяется
синтаксис через `node --check`.

## Отдельно про риск-контроль

Русификация интерфейса **не снижает риск блокировок**. Троттлинг настраивается
в `~/.dsh/web-login/gate.json` (интервалы, лимиты, максимальный объём промпта),
а сама надёжная альтернатива веб-каналу — официальный API `platform.deepseek.com`.
