# Роль: 05-chief-editor (Шеф-редактор — ВЫ)

> **Исполнитель:** **ВЫ (Человек / Владелец проекта)**  
> **Роль:** Главный арбитр качества и безопасности. Ни один бот или скрипт не имеет права публиковать статью в WordPress или выставлять статус `verified` без Вашего личного подтверждения.

---

## 1. Ваше рабочее место: Дашборд

Откройте в браузере файл:
```
D:\сайт для пайки\seo\dashboard\index.html
```

В колонке **«4. На ревью»** или **«5. Готово к ОТК»** кликните на карточку статьи. Всплывающее окно покажет полное досье:
- **Итоговый балл** (зелёный ≥80, жёлтый 60–79, красный <60).
- **Разбалловку по 6 категориям** (Факты, Интент, Голос, SEO, Ссылки, ИИ).
- **Список конкретных замечаний** (что сократить, какую ссылку добавить).
- **Красные блокеры** (если бот нашел ошибку в физике пайки или технике безопасности).

---

## 2. Ваши действия: Два сценария

### Сценарий А: Статья набрала ≥ 80 баллов и Вам нравится (Утверждение)
1. Вы принимаете статью.
2. Зафиксируйте решение в дашборде (`http://127.0.0.1:8765`, кнопка «✓ Утвердить») либо скриптом:
   ```bash
   python seo/scripts/sync_all_texts_to_db.py
   ```
   *Скрипт создаст резервную копию базы, перенесёт полный текст в `topics.content_markdown` и выставит статус `ready` через дашборд.*
3. После отправки черновика в WordPress (`delivery_cli.py`) Вы открываете запись в админке WordPress, нажимаете кнопку **«🛡️ Подтвердить проверку (ОТК)»** и публикуете пост (`publish`).

---

### Сценарий Б: Есть замечания или балл < 80 (Возврат на доработку)
1. Откройте файл замечаний:
   ```
   seo/out/scores/<ID>.md
   ```
2. Скопируйте список замечаний (например: *«сократить вводный абзац до 40 слов, добавить 1 ссылку на статью #1, вставить таблицу температур»*).
3. Передайте задачу Автору (`Claude Sonnet` или `Gemini Pro`).
4. После внесения правок повторно запустите скоринг:
   ```bash
   python seo/scripts/score_article.py --file "сами статьи/<ID>-<slug>.md" --id <ID>
   ```
   Если балл стал ≥ 80 — утверждайте по Сценарию А.

## 3. Чек-лист принятия финального решения

- [ ] В первом абзаце сразу дан ответ на вопрос, без рекламного разгона.
- [ ] Все температуры и сплавы подтверждены стандартами ГОСТ/IPC (нет выдуманных цифр).
- [ ] Текст читается легко и приятно (голос коллеги-инженера Practico, обращение на «Вы»).
- [ ] В тексте нет запрещённых стоп-фраз («абсолютно безопасно», «проще простого»).
- [ ] Нет ссылок на 404 (битые страницы).
- [ ] Скоринг `score_article.py` даёт оценку от 80 до 100 баллов.
