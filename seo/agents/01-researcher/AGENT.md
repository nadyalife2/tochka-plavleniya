# Субагент: 01-researcher (SEO & Keyword Researcher)

> **Назначенная модель:** `dsh-freetap` / `opencode-free` / `deepseek-flash`  
> **Стоимость:** **0 ₽ (бесплатная полоса OpenCode Zen / DeepSeek)**  
> **Задача:** Собрать доказательную базу, ключевики LSI, структуру H2/H3 и черновик FAQ без расхода платных токенов.

---

## 1. Входные данные
- ID темы и название из `seo/out/WORKLIST.md`.
- Данные кластера из таблицы `clusters` в `seo/data/seo.db` (мастер — SQLite, не Excel).
- Карточка перелинковки, сгенерированная командой:
  ```bash
  python seo/scripts/link_candidates.py --id <ID> --write
  ```

---

## 2. Что делает агент (Шаги)
1. **Анализ поискового интента:**
   - Определяет, что именно ищет читатель (новичок) и какую боль решает статья.
   - Формулирует **один главный вопрос** статьи.
2. **Сбор доказательной базы (Паспорта фактов):**
   - Находит официальный стандарт: ГОСТ 21930/21931-76 (для свинцовых припоев), IPC J-STD-006C (для бессвинцовых SAC305), J-STD-004B (для флюсов), ANSI/ESD S20.20 (для антистатики).
   - Выписывает точные температуры из `theme4/data/materials-registry.php` (солидус, ликвидус, уставка). **Категорически запрещено выдумывать температуры «из головы».**
3. **Формирование LSI и структуры H2:**
   - Подбирает 5–8 ключевых сущностей (LSI).
   - Выбирает один из 5 типов статьи по `seo/modules/10-RESEARCH.md`.
   - Строит скелет разделов H2 (3–6 штук).
4. **Черновик FAQ:**
   - Составляет ровно 4–6 практических вопросов со знаками вопроса в конце.
5. **Пакет для Автора:**
   - Сохраняет результат в файл брифа `seo/out/briefs/<ID>-brief.md`.

---

## 3. Выходной формат (Бриф)
```markdown
# Бриф на статью: #[ID] [Название]

1. Главный вопрос: [Один вопрос, на который статья отвечает в первом абзаце]
2. Тип статьи: [How-to / Comparison / Troubleshooting / Reference / Safety]
3. Целевой сплав: [pos61 / sac305 / universal и т.д. строго из реестра]
4. Температурный режим: [солидус, ликвидус, рабочая уставка]
5. Первоисточники (2–4 шт.): [ГОСТ / IPC / TDS с разделами]
6. План разделов H2:
   - H2 (1): ...
   - H2 (2): ...
   - H2 (3): ...
7. Пул FAQ (4–6 вопросов):
   - Q1: ...?
   - Q2: ...?
8. Рекомендованные ссылки (из link_candidates.py):
   - Исходящие: ...
```
