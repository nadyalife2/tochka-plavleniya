## 2. Реальный порядок подключения CSS в `theme3`

Согласно `theme3/includes/header.php`, стили подключаются строго в следующем каскадном порядке:

1. `assets/css/tokens.css` — системные дизайн-токены, переменные цветов, отступов и шрифтов.
2. `assets/css/fonts.css` — локальное подключение шрифтов Space Grotesk, Inter, JetBrains Mono.
3. `assets/css/build.css` — базовые утилиты сборки Tailwind.
4. Google Fonts: `Material Symbols Outlined` — иконки интерфейса.
5. `assets/css/base.css` — базовая верстка, типографика контента и стили разметки.
6. `assets/css/headphones-style.css` — специализированные нео-бруталистские компоненты `headphones` (hero, sideLogo, cards, marquee, pager, footer).

## 4. Причина конфликта тёмной темы и исправление

* **Исходная причина:** В `header.php` и `main.js` стояло автоматическое чтение медиа-запроса `window.matchMedia('(prefers-color-scheme: dark)')`. Если у пользователя на компьютере включена темная тема Windows/macOS, скрипт принудительно навешивал класс `html.dark`. В сочетании с белыми карточками и старыми классами это приводило к инверсии цветов и потере контрастности текста.
* **Решение:** Детерминированный светлый режим. При первом посещении тема всегда активируется в светлом режиме (`--bg: #f6f6f6`). Переключение в dark mode происходит исключительно при явном клике по переключателю пользователем.

## 6. Намеренные различия (Инженерия пайки vs Аудио-обзоры)

Тема `theme3` адаптирует визуальный язык, но строго сохраняет предметную инженерную область:

1. **Инженерный верстак (Lab Drawer):** Интерактивная выдвижная панель с быстрым расчетом теплофизики и выбором флюса/припоя (в Headphones этого блока нет).
2. **Чертежи и схемы (FIG. X.0):** Вместо фотографий наушников используются технические схемы микромонтажа (BGA, SMD 0402/0603, термопрофили) с режимом `object-fit: contain` для сохранения читаемости чертежей.
3. **Температурные бейджи:** Точечные акцентные плашки `#FFC700` (`280 °C`, `240 °C`, `650 °C`) для маркировки терморежимов жала и припоев.
4. **Бейдж ОТК / Метрология:** Служебный индикатор технического регламента и ссылки на ГОСТ / IPC-A-610.
