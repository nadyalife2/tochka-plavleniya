## 🚀 Быстрый старт: как выпустить новую статью за 15 минут

1. **Создайте черновик через ИИ**: скопируйте промпт из [Инструкции №01](./01-структура-и-написание-статей-для-нейросетей.md) в ChatGPT/Claude с вашей темой.
2. **Вставьте в Gutenberg**: в админке WordPress (`Записи → Добавить новую`) используйте готовые блоки из вкладки **«Паттерны» → «ТОЧКА ПЛАВЛЕНИЯ»**.
3. **Заполните карточку статьи**:
   - Выберите рубрику («Материалы и сплавы», «Практика и монтаж», «Проблемы и дефекты», «Старт и база»).
   - Добавьте метки через запятую (`#BGA`, `#SAC305`, `#NC-559`).
   - Напишите краткий отрывок (150–200 символов) — он пойдет в JSON-LD для ИИ.
   - Загрузите миниатюру.
4. **Опубликуйте**: статья сразу отобразится на главной, в рубрике, на страницах меток и получит валидную микроразметку.
