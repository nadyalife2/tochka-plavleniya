# Рекомендуемые плагины и обязательные настройки WordPress

> **Философия проекта «ТОЧКА ПЛАВЛЕНИЯ»**: Минимальный, легкий и надежный стек. Тема уже содержит встроенную дизайн-систему, 15 Gutenberg-паттернов, калькуляторы и Schema.org микроразметку. Поэтому плагины нужны только для системной оптимизации, медиа и SEO.

---

## 1. Рекомендуемый набор плагинов

| Плагин | Зачем нужен | Бесплатный? | Рекомендация по установке |
|--------|-------------|-------------|---------------------------|
| **Advanced Custom Fields (ACF)** | Удобные поля в карточке статьи: уровень сложности, норматив, список инструментов. | Да | **Обязательно** |
| **Converter for Media** или **WebP Express** | Автоматическая конвертация тяжелых фотографий плат в легкий формат `.webp` (ускоряет загрузку в 3–5 раз). | Да | **Обязательно** |
| **The SEO Framework** или **Rank Math** | Генерация XML-карты сайта (`sitemap.xml`) и управление каноническими URL. | Да | **Обязательно** (выбрать один) |
| **LiteSpeed Cache** (или **WP Super Cache**) | Кэширование страниц в оперативную память сервера, gzip-сжатие, мгновенная отдача страниц. | Да | **Обязательно** |
| **WPS Hide Login** | Смена стандартного адреса `/wp-login.php` на секретный для защиты от брутфорс-ботов. | Да | **Рекомендуется** |
| **Classic Widgets** (если требуется) | Не обязателен, тема использует чистый modern layout. | Да | По желанию |

## 2. Пошаговая настройка плагина Advanced Custom Fields (ACF)

Чтобы автору не приходилось вручную прописывать произвольные поля, создайте группу полей через ACF:

1. В админке перейдите в **ACF (Группы полей) → Добавить новую**.
2. Назовите группу: **«Инженерные метаданные ТЧП»**.
3. Добавьте 3 поля:
   - **Поле 1**:
     - *Ярлык поля*: Отраслевой норматив
     - *Имя поля*: `tchp_standard`
     - *Тип*: Текст
     - *Значение по умолчанию*: `ГОСТ / IPC-A-610`
   - **Поле 2**:
     - *Ярлык поля*: Уровень квалификации
     - *Имя поля*: `proficiency_level`
     - *Тип*: Выбор (Select)
     - *Варианты*:  
       `Beginner : Для начинающих`  
       `Intermediate : Средний уровень`  
       `Expert : Эксперт / PRO`
   - **Поле 3**:
     - *Ярлык поля*: Необходимое оборудование (через запятую)
     - *Имя поля*: `required_tools`
     - *Тип*: Текст
     - *Пример*: `Термофен, Флюс NC-559, Припой SAC305, Термопара`
4. В блоке **«Условия отображения»** выберите:  
   *Тип записи* — *равно* — *Запись (Post)*.
5. Нажмите **Сохранить изменения**.  
   *Теперь под редактором каждой статьи появятся удобные поля ввода.*

## 3. Обязательные настройки самого WordPress

После установки или переноса сайта обязательно проверьте следующие системные настройки:

### 1. Постоянные ссылки (ЧПУ — Пермалинки)
- Путь: **Настройки → Постоянные ссылки**.
- Выберите вариант: **«Название записи»** (`/%postname%/`).
- Нажмите **Сохранить изменения**.  
  *Это создаст чистые человекопонятные URL без знаков вопроса (`/temperaturnye-profili/` вместо `/?p=101`), что критично для поисковиков.*

### 2. Настройки чтения (Главная страница)
- Путь: **Настройки → Чтение**.
- В пункте *«На главной странице отображать»*:
  - Выберите **«Ваши последние записи»**.
  - Шаблон темы `front-page.php` / `index.php` автоматически оформит красивую главную страницу со скетчевым верстаком, интерактивными карточками задач и лентой свежих статей.
- В пункте *«Видимость для поисковых систем»*:
  - Убедитесь, что галочка *«Попросить поисковые системы не индексировать сайт»* **СНЯТА**.

### 3. Настройки обсуждения (Комментарии и спам)
- Путь: **Настройки → Обсуждение**.
- В теме уже программно отключены комментарии для соблюдения 152-ФЗ (Zero-PII).
- Для надежности снимите галочку: *«Разрешить оставлять комментарии на новые записи»*.

### 4. Настройки медиафайлов
- Путь: **Настройки → Медиафайлы**.
- Рекомендуемые размеры:
  - *Миниатюра*: 400 × 225 (обрезать миниатюру точно по размеру).
  - *Средний*: 800 × 450.
  - *Крупный*: 1200 × 675.
- Снимите галочку *«Помещать загруженные файлы в папки по месяцам и годам»* (или оставьте по вашему предпочтению).

## 4. Настройка SEO-плагина (The SEO Framework или Rank Math)

Поскольку в тему уже встроена микроразметка `TechArticle`:
1. В настройках SEO-плагина включите генерацию XML-карты сайта (`sitemap.xml`).
2. В файле `robots.txt` проверьте директиву:  
   `Sitemap: https://tochka-plavleniya.ru/sitemap.xml`.
3. Если SEO-плагин предлагает генерировать Schema.org статью по умолчанию, отключите его тип «Article» или оставьте «WebPage», чтобы не дублировать встроенную инженерную разметку `TechArticle`.

## 5. Проверка доступности служебных файлов для ИИ

Откройте в браузере следующие ссылки:
1. `https://tochka-plavleniya.ru/robots.txt` — должен отдаваться файл с разрешением краулерам `GPTBot`, `ClaudeBot`, `PerplexityBot`.
2. `https://tochka-plavleniya.ru/llms.txt` — должен открываться текстовый индекс базы знаний.
3. `https://tochka-plavleniya.ru/interactive` — страница инструментов верстака должна открываться без ошибок.
4. `https://tochka-plavleniya.ru/privacy` — политика конфиденциальности.
5. `https://tochka-plavleniya.ru/terms` — пользовательское соглашение.
