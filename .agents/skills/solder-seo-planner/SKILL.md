# Solder SEO Planner — Инженерный SEO-Архитектор

Специализированный скилл для семантической разметки, оптимизации сниппетов, работы со структурированными данными и управления представлением в поисковиках и ИИ-ответах.

## When to Use

- При составлении мета-тегов (`title`, `description`, `focus_keyword`) для Rank Math SEO.
- При кластеризации запросов семантического ядра.
- При подготовке структурированных данных FAQ для отображения расширенных сниппетов (Rich Snippets).
- При планировании перелинковки между статьями и интерактивными калькуляторами.

## Quick Start

**Оптимизация сниппета для Rank Math:**
- `Title`: 50–60 символов, главное ключевое слово ближе к началу, разделитель «— Точка Плавления».
- `Description`: 140–160 символов, содержит практическую пользу, диапазон температур и призыв к действию.
- `Focus Keyword`: основной поисковый запрос (например, «температура пайки ПОС-61»).

## 1. Правила SEO «Точки Плавления»

1. **Rank Math — единственный владелец Schema.org:**
   Мы не пишем самодельную разметку `Article` или `FAQPage` в HTML-шаблонах, чтобы избежать дублей. Всё управление разметкой передаётся модулю Rich Snippets плагина Rank Math.
2. **Семантическая иерархия:**
   - Единственный `<h1>` на странице.
   - Подзаголовки `<h2>` и `<h3>` соответствуют реальным поисковым запросам и вопросам пользователей.
3. **LLMS.txt и ИИ-поисковики:**
   Контент структурируется так, чтобы поисковые модели (Perplexity, ChatGPT Search, Яндекс Нейро) могли мгновенно извлечь прямой ответ на вопрос читателя из первых двух абзацев секции.
