# TCHP Business Model

Собирает и проверяет бизнес-модель проекта: два контентных сайта и устройство
для интенсификации теплоотдачи радиатора. Не заменяет финансовую модель —
для цифр используйте `tchp-unit-economics`.

## When to Use

- Нужен Lean Canvas на сайт, устройство или весь проект.
- Нужно выбрать три потока дохода и цены.
- Нужно проверить, кому и зачем нужен продукт.
- Перед запуском нового сайта, продукта или гранта.

## Workflow

### 1. Сегменты и работа (JTBD)
1. Для сайта №1: мастер сервисного центра, домашний мастер, начинающий.
2. Для сайта №2: собственник жилья, домашний мастер, бригада/мастер.
3. Для устройства: владелец квартиры с водяным радиатором, мастер по отоплению.
4. Сформулировать «работу»: «быстро понять режим», «не переплатить за инструмент»,
   «убрать холодную зону у окна», «сделать без сверления и слива».

### 2. Lean Canvas
Заполнить 9 блоков + «Time & Energy»:

| Блок | Вопрос |
|---|---|
| Problem | 1–3 боли сегмента |
| Customer segments | кто платит и кто пользуется |
| Unique value proposition | одно предложение |
| Solution | 3–5 фич/форматов |
| Channels | поиск, Telegram, YouTube/Rutube, партнёрки |
| Revenue streams | услуги, PDF, партнёрка, лиды, устройство |
| Cost structure | домен, хостинг, время, съёмка, прототип |
| Key metrics | трафик, подписки, продажи, RPM |
| Unfair advantage | паспорт статьи, калькуляторы, ГОСТ/IPC, устройство |
| Time & Energy | 15–20 ч/нед, что делаем сами |

### 3. Три потока дохода
1. **Быстрый (2–4 недели):** консультации, разбор схемы/пайки, B2B-статья,PDF-техкарта.
2. **Средний (2–4 месяца):** партнёрские ссылки, продажи PDF, лид-генерация на мастеров.
3. **Поздний (5–9 месяцев):** РСЯ, спонсоры, курс, устройство/набор.

### 4. Цены
- PDF-техкарта: 490–1490 ₽.
- Разбор/консультация: 1500–6000 ₽.
- B2B-статья: 3000–8000 ₽.
- Устройство (kit): 4000–6000 ₽; собранное: 9000–14000 ₽.
- Лид мастеру: 500–2000 ₽ за подтверждённый контакт.

### 5. Проверка гипотез
1. 10–15 интервью по `docs/customer-interviews-guide.md` (если создан).
2. Предпродажа PDF до написания.
3. 10 писем мастерским с оффером B2B-статьи.
4. Лендинг устройства с формой «хочу набор».
5. Критерии: 3+ предоплаты, 2+ B2B-ответа, 5+ заявок на устройство.

## Rules

- Числа — только с допущениями и источниками; оценки помечать.
- Не считать гранты доходом.
- Один новый сайт за раз; третий — только после гейтов.
- Сначала услуги/продукт, потом реклама.
- Не обещать доход без проверки спроса.
