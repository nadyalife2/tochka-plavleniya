# TCHP Unit Economics

Считает, сходится ли экономика проекта на уровне одного посетителя, клиента,
статьи и устройства. Работает с вилками и допущениями, а не с «точными» цифрами.

## When to Use

- Нужна финмодель на 6–12 месяцев.
- Нужно понять, сколько стоит клиент и когда он окупается.
- Нужно сравнить сценарии: пессимистичный / базовый / оптимистичный.
- Нужно посчитать точку безубыточности по трафику и продажам.

## Входные данные

| Параметр | Обозначение | Где взять |
|---|---|---|
| Визиты/мес | `S` | Метрика, Search Console, прогноз |
| Доход с 1000 визитов | `RPM` | партнёрка, РСЯ, лиды |
| Конверсия в продукт | `c` | продажи / визиты |
| Средний чек | `AOV` | прайс |
| Маржа продукта | `m` | цена − себестоимость |
| Затраты на контент | `C_content` | часы × ставка |
| Затраты на клиента | `CAC` | реклама/аутрич/время |
| Срок жизни | `L` | месяцы повторных покупок |

## Формулы

```
RPM          = revenue / sessions * 1000
ARPU         = revenue / customers
Contribution = AOV * m
LTV          = ARPU * m * L
Payback      = CAC / (ARPU * m)
Breakeven S  = fixed_costs / (RPM / 1000)
Breakeven N  = fixed_costs / Contribution
ROI          = (LTV - CAC) / CAC
```

## Workflow

### 1. Собрать допущения
1. Трафик: консервативно 30–50% от прогноза SEO.
2. RPM: партнёрка 300–800 ₽, РСЯ 50–120 ₽ на 1000 визитов.
3. Конверсия PDF: 0,2–1%; услуги: 0,1–0,5% визитов; B2B: 1–3 ответа на 10 писем.
4. Себестоимость устройства: BOM 3–6 тыс. ₽ + сборка/упаковка.
5. Время: 15–20 ч/нед; ставка часа — альтернативная стоимость.

### 2. Сценарии
Для каждого сайта и устройства:

| Сценарий | Трафик | RPM | Конверсия | Чек | Доход |
|---|---:|---:|---:|---:|---:|
| Пессимистичный | низкий | низкий | низкая | низкий | ... |
| Базовый | средний | средний | средняя | средний | ... |
| Оптимистичный | высокий | высокий | высокая | высокий | ... |

### 3. Точка безубыточности
1. Постоянные: домен, хостинг, инструменты, подписки.
2. Переменные: контент, съёмка, упаковка, доставка.
3. Посчитать, сколько визитов/клиентов нужно, чтобы покрыть постоянные.

### 4. Чувствительность
- RPM ±30%.
- Конверсия ±50%.
- Трафик ±50%.
- Чек ±20%.
Показать, какой параметр двигает доход сильнее всего.

## Output

`docs/unit-economics-<project>.md`:
1. Допущения (таблица).
2. Формулы.
3. Сценарии на 3/6/12 месяцев.
4. Точка безубыточности.
5. Чувствительность.
6. Решения: continue / pivot / stop.

## Rules

- Не выдавать оценки за факты; помечать «допущение».
- Не считать гранты и разовые продажи повторяемым доходом.
- Считать время как минимум альтернативной стоимостью.
- Если payback > 12 месяцев — пересмотреть оффер.
- Проверять модель на реальных данных после 30/60/90 дней.
