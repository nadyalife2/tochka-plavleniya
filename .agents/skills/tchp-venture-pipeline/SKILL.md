# TCHP Venture Pipeline — сквозной контур «идея → сайт → доход → изобретение»

Единый оркестратор для проекта «Точка Плавления». Ведёт от гипотезы до денег
и от идеи устройства до заявки на патент/грант. Не заменяет узкие скиллы
(`solder-researcher`, `solder-writer`, `solder-reviewer`, `solder-seo-planner`,
`solder-wordpress-publisher`, `tchp-editorial-standards`, `brand`, `build-partner`),
а определяет порядок их применения и артефакты.

## When to Use

- Стратегия роста, портфель сайтов, «второй сайт», «первый доход».
- Бизнес-модель, юнит-экономика, цены, каналы, воронка.
- Запуск/развитие сайта: бренд, семантика, контент, SEO/GEO, монетизация.
- Изобретение: крепление, комплектующие, прототип, патентный поиск, гранты.
- Нужно свести разрозненные документы в один план и довести до артефакта.

**Не использовать** для чисто редакторских задач (там `solder-*`), для вёрстки
(там `impeccable`/`ui-*`) и для кода вне контент-платформы.

## Режимы

| Режим | Вход | Выход |
|---|---|---|
| `validate` | ниша/идея | скоринг спроса, конкуренты, риски, решение go/no-go |
| `model` | выбранная ниша | Lean Canvas, 3 потока дохода, финмодель по месяцам |
| `site` | бренд/домен | чек-лист запуска сайта, семантика, контент-план |
| `content` | кластер | календарь статей/видео, формат, дистрибуция |
| `money` | трафик/аудитория | план монетизации, цены, пороги, KPI |
| `invent` | идея устройства | матрица признаков, патентный поиск, BOM, прототип |
| `gates` | факт месяца | решение continue/pivot/stop |

## Workflow

### 0. Бриф (15 минут)
Зафиксировать: цель, горизонт, кэш-бюджет, часы/неделю, текущие активы,
ограничения (не показывать лицо, один человек, Самара). Артефакт:
`docs/venture-brief.md` или раздел в текущем плане.

### 1. Проверка идеи (`validate`)
1. Спрос: Wordstat/Вебермастер/Google Trends/конкуренты (sitemap).
2. Конкуренты: 5–10 игроков, их форматы, цены, слабые места.
3. Юнит-экономика на салфетке: RPM, конверсия, средний чек.
4. Скоринг: спрос × монетизация × ваша экспертиза × стоимость контента ÷ конкуренция.
5. Решение: go / pivot / no-go. Артефакт: `docs/validation-<niche>.md`.

### 2. Бизнес-модель (`model`)
1. Lean Canvas на один экран.
2. Три потока дохода: быстрый (услуги/B2B), средний (продукт), поздний (реклама).
3. Цены: PDF 490–1490 ₽, услуга 1500–6000 ₽, B2B-статья 3000–8000 ₽.
4. Финмодель по месяцам: трафик → конверсия → доход → расходы.
5. Артефакт: `docs/business-model-<project>.md`.

### 3. Запуск сайта (`site`)
1. Бренд: название, домен, лого, палитра (по `DESIGN.md`).
2. WordPress: `theme4` + `tchp-content`, Rank Math, кэш, SSL.
3. Рубрики, семантика (100–150 запросов), 5–10 эталонных статей.
4. Калькуляторы: 1–2 на старте.
5. SEO/GEO: canonical, OG, JSON-LD, `llms.txt`, sitemap, скорость.
6. Аналитика: Метрика, Вебмастер, Search Console.
7. Артефакт: `docs/site-launch-<site>.md` + чек-лист.

### 4. Контент-двигатель (`content`)
1. Ритм: 2 статьи/нед на сайт №1, 1–1,5 на №2; 1 видео-сессия/мес.
2. Формат статьи: TL;DR → паспорт → регламент → таблицы → FAQ → источники → CTA.
3. Видео: 1 длинное + 5–8 shorts, кросс-постинг.
4. Дистрибуция: сайт → Telegram → Rutube/VK/Дзен → YouTube.
5. Артефакт: контент-календарь на 4 недели.

### 5. Монетизация (`money`)
1. Сначала услуги/консультации и B2B-статьи (деньги в 2–4 недели).
2. Затем цифровой продукт (PDF/сметы) и партнёрские ссылки.
3. РСЯ — не раньше 3–5 тыс. визитов/мес.
4. Спонсоры — после 10 тыс. подписчиков/визитов.
5. Правила: ≤1 рекламный блок на экран, маркировка, `rel=sponsored`.
6. Артефакт: `docs/monetization-plan.md`.

### 6. Изобретение (`invent`)
1. ТРИЗ/морфологический анализ: функции → варианты → выбор.
2. Патентный поиск: ФИПС/Роспатент-платформа, Google Patents, Espacenet;
   классы `F24D`, `F04D`, `H01L 35/00`, `H02N 11/00`.
3. Матрица признаков: ваше устройство vs RU95183U1, Caframo US20210408353A1, MDPI.
4. Прототип: BOM из `docs/DEVICE-MOUNT-BOM.md`, замеры ΔT/мощности/старта.
5. Заявка на полезную модель — **до публикации** (льгота 6 мес; промобразец 12).
6. Гранты: «УМНИК» (18–35), мини-грант Сколково, «Мой бизнес», Жигулёвская долина.
7. Артефакт: `docs/invention-<device>.md` + матрица + черновик формулы.

### 7. Гейты и рост (`gates`)
1. Ежемесячный обзор: трафик, подписчики, доход, конверсия.
2. Гейты: 14 дней — первые продажи; 30 — 5–15 тыс. ₽; 90 — 15–30 тыс. ₽;
   180 — 30–60 тыс. ₽.
3. Стоп-факторы: нет индексации → техаудит; нет продаж → оффер; выгорание →
   снизить темп до 1 статьи/нед.
4. Артефакт: `docs/growth-review-YYYY-MM.md`.

## Rules & Invariants

- **Один новый сайт за раз.** Третий сайт — только после 10 тыс. визитов/мес
  на первом и стабильного дохода.
- **Сначала деньги, потом масштаб.** Услуги/продукт раньше рекламы.
- **Минимальные затраты.** Никакой рекламы на трафик, нового железа и платных
  курсов до подтверждения спроса.
- **Патент раньше публикации.** Технические детали — после приоритета.
- **Гранты не считать доходом.** Это лотерея с подготовкой; бюджет — без них.
- **Честные цифры.** Оценки помечать как оценки; источники — ссылками.
- **Юридика.** НПД/ИП/ООО по этапу, чеки, маркировка рекламы, 152-ФЗ.
- **YMYL.** Для ремонта/пайки — рецензент, ГОСТ/СП/IPC, дисклеймеры.
- **Дизайн.** Editorial Lab из `DESIGN.md`; не заменять на generic SaaS.
- **Код и файлы** менять только после явного согласования плана (AGENTS.md).
- **Каждый режим заканчивается артефактом** в `docs/` или рабочей папке.
