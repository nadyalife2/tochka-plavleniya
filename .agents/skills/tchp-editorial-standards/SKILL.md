# Точка Плавления — Редакционные и Технические Стандарты (v1.2)

Этот скилл содержит канонические правила создания, валидации и публикации материалов на инженерном портале «Точка Плавления» (tochka-plavleniya.ru).

## When to Use

- При подготовке, генерации или рецензировании технических статей по пайке.
- При валидации метаполей статьи по схеме `article-contract-v1.1.schema.json`.
- При контроле физической достоверности температур, сплавов, классов флюсов и оснастки.
- При упаковке паспорта статьи через `seo/scripts/package_contract.py`.
- При выгрузке статей через `tools/delivery_cli.py` в WordPress REST API.
- При проверке UI Сплит-Верстака и дашборда на соответствие регламенту `AGENTS.md` (no emojis, industrial sketch aesthetic).
- При проведении приёмочного тестирования `python tests/run-all-tests.py` и `python tools/run_comprehensive_playwright.py`.

## Quick Start & Verification

**1. Проверка полного тестового комплекса (7 шагов):**
```bash
python tests/run-all-tests.py
```

**2. Playwright E2E аудит дашборда и темы на 4 разрешениях (375, 768, 1024, 1440):**
```bash
python tools/run_comprehensive_playwright.py
```

**3. Валидация паспорта и текста статьи по схеме v1.1:**
```bash
python seo/scripts/package_contract.py <TOPIC_ID>
```

**4. Безопасная доставка в WordPress (Dry-Run):**
```bash
python tools/delivery_cli.py deliver --topic <TOPIC_ID> --dry-run
```

**5. CLI-справочник стандартов с выводом физических свойств:**
```bash
python seo/scripts/standards_lookup.py pos61 --json
```

## 1. Канонические Сплавы и Температуры (SSOT)

Единый источник истины по материалам: [`theme4/data/materials-registry.php`](../../../theme4/data/materials-registry.php).
Все вспомогательные справочники (`alloys.json`, `standards_matrix.json`) обязаны строго соответствовать этому реестру.

| Ключ (Slug) | Марка припоя | Нормативный документ | Солидус / Ликвидус | Уставка жала | Тип кристаллизации |
|:---|:---|:---|:---|:---|:---|
| `pos61` | ПОС-61 (Sn61Pb39) | ГОСТ 21930/21931-76 | 183 / 190 °C | 240 – 320 °C | Не эвтектика (интервал 7 °C) |
| `sn63pb37` | Sn63Pb37 | IPC J-STD-006C / ASTM B32 | 183 / 183 °C | 250 – 285 °C | Истинная эвтектика (0 °C) |
| `pos40` | ПОС-40 | ГОСТ 21930/21931-76 | 183 / 238 °C | 280 – 330 °C | Не эвтектика (интервал 55 °C) |
| `sac305` | SAC305 | IPC J-STD-006C | 217 / 220 °C | 260 – 340 °C | Бессвинцовый RoHS (интервал 3 °C) |
| `sac405` | SAC405 | IPC J-STD-006C | 217 / 220 °C | 265 – 345 °C | Бессвинцовый (4% Ag) |
| `sn42bi58` | Sn42Bi58 | СТП / ASTM | 138 / 138 °C | 160 – 200 °C | Низкотемпературная эвтектика |
| `snbiago` | Sn42Bi57.6Ag0.4 | Chip Quik SMDLTLFP | 137 / 140 °C | 165 – 205 °C | Низкотемпературный легированный |
| `roze` | Сплав Розе (Bi50Pb32Sn18) | ТУ 6-09-4064-87 | 94 / 96 °C | 120 – 150 °C | Демонтажный (не эвтектика, 2 °C) |
| `vuda` | Сплав Вуда | ТУ 6-09-4065-88 | 68.5 / 68.5 °C | 110 – 145 °C | Токсичный демонтажный (12.5% Cd) |
| `universal` | Универсальный | — | — | — | Только для обзорных статей |

### Критические физические ограничения
1. **Запрет линейной арифметики:** Запрещены формулы вида «ликвидус + 60…90 °C» или «+75…150 °C». Уставка жала задается только технологическим окном конкретного сплава с учетом теплоемкости спаиваемого узла.
2. **Сплав Розе:** Состав — строго `Bi 50%, Pb 32%, Sn 18%` (ТУ 6-09-4064-87). Не является эвтектикой (интервал 2 °C). Запрещен для постоянного монтажа.
3. **Флюс ORH1:** Не запрещен для электроники, но требует обязательной деионизированной гидросмывки (DI water wash).
4. **ЛТИ-120:** Спиртоканифольный активированный флюс (Группа II по ГОСТ 19250-73), не кислота.

## 2. Архитектура нулевых галлюцинаций (Zero-Hallucination Guard)

В скрипте [`seo/scripts/package_contract.py`](../../../seo/scripts/package_contract.py) действуют строгие защитные барьеры:

1. **Запрет тихих подстановок:** Если в тексте статьи автор не указал рабочую температуру уставки жала, упаковщик **не имеет права** подставлять коридор из реестра или заменять температурой плавления. Статья бракуется до явного указания режима.
2. **Контроль физической инверсии (Windowed Proximity):**
   * В радиусе 45 символов вокруг каждого числа `NNN °C` проверяется смысловой контекст.
   * Число уставки жала (>240 °C) не может стоять рядом со словами «плавится / ликвидус».
   * Число плавления (183 °C) не может объявляться «уставкой жала».
3. **Фильтрация отрицаний при детекции инструментов:**
   * Обороты «без паяльника», «паяльник не требуется» не добавляют паяльник в оснастку.
   * «Лупа» не нормализуется в «Микроскоп». Обычный пинцет не становится «Термопинцетом».
4. **Очистка frontmatter:** Перед формированием лида/excerpt из Markdown вырезаются YAML frontmatter (`---...---`) и заголовок `# H1`.

## 3. Редакционный Контракт v1.1 и WordPress Плагин

Файлы схемы и плагина:
- [`schemas/article-contract-v1.1.schema.json`](../../../schemas/article-contract-v1.schema.json)
- [`wp-content/plugins/tchp-content/tchp-content.php`](../../../wp-content/plugins/tchp-content/tchp-content.php)

### Обязательные требования к статье v1.1
- **Answer First:** Суть и режим в первом абзаце объёмом **строго ≤ 40 слов**. В верстаке работает живой бейдж `[LID: N/40 СЛОВ]`.
- **FAQ:** Блок `### FAQ:` обязан содержать **от 4 до 6 вопросов-ответов** (строго по схеме `minItems: 4`).
- **Источники:** Блок `## Источники:` обязан содержать **не менее 2 подтверждённых нормативов** (ГОСТ / IPC / заводской TDS).
- **Сложность (`tchp_difficulty`):** Разрешены значения `['Базовый', 'Инженер', 'Эксперт', 'Практик']`.
- **Версия схемы (`tchp_schema_version`):** Разрешены `['1.0', '1.1']`.

## 4. Эргономика Редакционного Сплит-Верстака

Интерфейс верстака ([`seo/dashboard/index.html`](../../../seo/dashboard/index.html), [`dashboard.css`](../../../seo/dashboard/dashboard.css), [`dashboard.js`](../../../seo/dashboard/dashboard.js)):

1. **Сплит-сетка:** При закрытом сайдбаре текстовый редактор занимает 100% полезной ширины модалки. Правая колонка 380 px подключается только при активном классе `.workbench-expanded` (кнопка `[ВЕРСТАК]`).
2. **Вставка сниппетов:** Выполняется через `editor.setRangeText(snippet, start, end, 'end')` с поддержкой выделения и корректной работой в позиции 0.
3. **Плейсхолдеры вместо дефолтов:** Сниппет «Паспорт процесса» вставляет незаполненные маркеры `[Укажите сплав]` и `[Укажите уставку]`, исключая случайную публикацию предустановленного ПОС-61.
4. **Автосохранение в `localStorage`:** Черновик автоматически сохраняется по ключу `tchp_draft_${topicId}` с дебаунсом 350 мс. При открытии темы предлагается восстановление или сброс к БД.
5. **Дизайн-код `AGENTS.md`:** Запрещены эмодзи как UI-иконки. Кнопки оформлены строгими техническими плашками в скобках (`[ШАБЛОН]`, `[ПРЕВЬЮ]`, `[СОХРАНИТЬ В БД]`, `[ИСТОЧНИК ФАКТА]`).

## 5. AEO & Поисковый Контур под Google без Трекеров

1. **Дифференциация ботов в [`robots.txt`](../../../robots.txt):**
   * **Разрешены поисковые и цитирующие боты:** `Googlebot`, `OAI-SearchBot`, `ChatGPT-User`, `Claude-SearchBot`, `PerplexityBot`, `YandexBot`, `Bingbot`.
   * **Заблокированы обучающие скрейперы весов:** `GPTBot`, `ClaudeBot`, `Google-Extended`, `CCBot`.
   * **Служебные пути:** `/wp-admin/`, `/wp-includes/`, `/includes/`, `/data/`, `/tools/`, `/seo/`, `/tests/` закрыты для всех ботов.
2. **Манифест [`/llms.txt`](../../../llms.txt):**
   * Содержит ссылки только на фактически опубликованные статьи (`status = 'published'` или валидный `wp_url`). Черновики исключены.
3. **Автономный сбор семантики:**
   * Скрипт [`seo/scripts/google_semantics.py`](../../../seo/scripts/google_semantics.py) собирает поисковые подсказки Google Suggest и вопросительные AEO-модификаторы («как», «чем», «какая температура») без платных API и пишет в таблицу `google_semantics` в `seo.db`.
   * Доступен через эндпоинт `GET /api/semantics/google?q=...`.
