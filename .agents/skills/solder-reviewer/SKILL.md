# Solder Reviewer — Шеф-Редактор и Инженерный Контролёр Качества

Специализированный скилл для строгой технической приёмки, фактчекинга, проверки безопасности и подготовки статей к верификации отпечатком SHA-256.

## When to Use

- Перед утверждением и передачей статьи в WordPress.
- Для выявления опасных советов, некорректных температурных режимов и ошибок в сплавах.
- Для проверки отсутствия мусорных фраз и штампов.
- Для контроля готовности метаполей статьи (сплав, температуры, инструменты, FAQ).

## Quick Start

**Проверка статьи по чек-листу:**
1. Проверить соответствие диапазонов температур каноническому справочнику сплавов.
2. Проверить правила техники безопасности.
3. Запустить поиск стоп-слов из `forbidden_phrases.txt`.
4. Сформировать вердикт: `Одобрено` / `Требует правок` / `Отклонено`.

---

## 1. Чек-лист Технической Приёмки

- [ ] **Сплавы:** Указан канонический slug (`pos61`, `sn63pb37`, `pos40`, `sac305`, `sac405`, `sn42bi58`, `snbiago`, `roze`, `vuda`, `universal`).
- [ ] **Температуры:** Диапазон в паспорте реалистичен (например, для ПОС-61: ликвидус 190 °C, жало 260–300 °C с учётом теплопотерь).
- [ ] **Безопасность:** Есть предупреждение о вытяжке/проветривании, мытье рук после свинца и защите компонентов от перегрева.
- [ ] **Чистота языка:** Нет штампов («ни для кого не секрет», «как известно», «удивительный мир электроники»).
- [ ] **Честность виджетов:** Нет симуляций («QC PASSED по IPC»), только корректные названия калькуляторов.
- [ ] **Инструменты:** Все упомянутые приборы и расходники указаны с конкретными типами (жало, флюс, припой).
- [ ] **FAQ:** Вопросы сформулированы практично, ответы лаконичны и не противоречат основному тексту.

---

## 2. Подготовка к Редакционной Верификации

Когда статья прошла проверку:
1. Фиксируется имя проверяющего (`verified_by`).
2. Фиксируется дата (`verified_at`).
3. Рассчитывается отпечаток статьи (SHA-256):
   `hash = SHA256(title + content + solder_alloy + temp_min + temp_max + tools + sources)`.
4. Статья готова к подтверждению через REST API с защитой `expected_hash`.
