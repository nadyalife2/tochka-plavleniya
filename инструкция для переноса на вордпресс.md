# 🚀 Инструкция по переносу верстки на WordPress — Тема «Точка Плавления»

Данный документ содержит пошаговое руководство по превращению текущего PHP-проекта и верстки в полноценную, готовую к работе тему **WordPress** с поддержкой автоматической GEO микроразметки (Schema.org / JSON-LD) для ИИ-поисковиков.

---

## 📂 1. Структура файлов темы WordPress

Скопируйте содержимое папки `site` или `wp-content/themes/tochka-plavleniya` в директорию вашего сайта WordPress:
`/wp-content/themes/tochka-plavleniya/`

### Файловая структура темы:
```
wp-content/themes/tochka-plavleniya/
├── style.css                 # Заголовок темы WP и основные стили
├── functions.php             # Регистрация функций WP, хуков и GEO-микроразметки
├── header.php                # Шэпка сайта, вызов wp_head() и JSON-LD
├── footer.php                # Подвал сайта, подвал и вызов wp_footer()
├── index.php                 # Главная страница (Цикл постов WordPress)
├── single.php                # Шаблон отдельной статьи (бывший article.php)
├── page-interactive.php      # Шаблон страницы «Инструменты» (бывший interactive.php)
├── category.php              # Архив категории / тегов
├── 404.php                   # Страница ошибки 404
├── llms.txt                  # Файл данных для ИИ-краулеров (ChatGPT/Perplexity)
├── assets/
│   ├── css/                  # style.css, article.css, interactive.css
│   └── js/                   # flux-calc.js, solder-quiz.js, solder-table.js
└── includes/
    ├── functions.php         # Вспомогательные функции и GEO-разметка
    ├── articles-data.php     # Демо-данные (для автономного режима)
    └── cookie-banner.php     # Баннер согласия с Cookies
```

## 📝 2. Оформление `style.css` для распознавания темы WordPress

Файл `/wp-content/themes/tochka-plavleniya/style.css` должен начинаться с обязательного заголовка WordPress:

```css

Text Domain: tochka-plavleniya
*/
```

## ⚙️ 3. Настройка `functions.php` в теме WordPress

В основном файле `functions.php` темы зарегистрируйте стили, скрипты и поддержку миниатюр постов:

```php
<?php
/**
 * Main Theme Functions
 */

require_once get_template_directory() . '/includes/functions.php';

function tochka_plavleniya_setup() {
    // Поддержка тега <title>
    add_theme_support('title-tag');
    
    // Поддержка миниатюр постов (Featured Images)
    add_theme_support('post-thumbnails');
    
    // Регистрация меню
    register_nav_menus([
        'primary' => 'Главное меню шапки',
        'footer'  => 'Меню подвала'
    ]);
}
add_action('after_setup_theme', 'tochka_plavleniya_setup');

function tochka_plavleniya_scripts() {
    // Подключение стилей
    wp_enqueue_style('google-fonts', 'https://fonts.googleapis.com/css2?family=Hanken+Grotesk:wght@700;800&family=IBM+Plex+Mono:wght@500;700&family=Inter:wght@400;500;600;700&family=Fraunces:opsz,wght@9..144,300;600;800&display=swap', [], null);
    wp_enqueue_style('tochka-main-style', get_template_directory_uri() . '/assets/css/style.css', [], '1.0');

    // Подключение специфичных скриптов для интерактивной страницы
    if (is_page_template('page-interactive.php') || is_page('interactive')) {
        wp_enqueue_style('tochka-article-css', get_template_directory_uri() . '/assets/css/article.css', [], '1.0');
        wp_enqueue_script('flux-calc', get_template_directory_uri() . '/assets/js/flux-calc.js', [], '1.0', true);
        wp_enqueue_script('solder-quiz', get_template_directory_uri() . '/assets/js/solder-quiz.js', [], '1.0', true);
        wp_enqueue_script('solder-table', get_template_directory_uri() . '/assets/js/solder-table.js', [], '1.0', true);
    }
}
add_action('wp_enqueue_scripts', 'tochka_plavleniya_scripts');
```

## 🏷️ 4. Произвольные поля (Custom Fields / ACF) для статей

Чтобы данные для ИИ-разметки (GEO) формировались **автоматически прямо из админки WordPress**, установите плагин **Advanced Custom Fields (ACF)** (или используйте стандартные мета-поля):

Создайте группу полей для постов:
1. **`proficiency_level`** (Тип: Выбор / Select):
   - `Beginner` — Для новичков
   - `Intermediate` — Средний уровень
   - `Expert` — Профессиональный / Эксперт
2. **`required_tools`** (Тип: Текст / Text):
   - Значение: список используемого оборудования через запятую (например: `Паяльная станция Quick 861DW, Флюс NC-559, Припой SAC305`).
3. **`card_icon`** (Тип: Выбор / Select):
   - Значения: `chip`, `tools`, `thermometer`, `drop`, `board` (для автоматического выбора SVG-иконки в карточке).

## 🧠 5. Как работает автоматическая GEO-разметка для ИИ

В файле `header.php` вашей темы вызван специальный обработчик:

```php
<?php if (function_exists('render_geo_schema')) render_geo_schema(); ?>
```

### Как это работает автоматически:
1. Когда пользователь или ИИ-бот (ChatGPT / Perplexity) открывает любую статью на базе WordPress, функция `render_geo_schema()` **автоматически**:
   - Извлекает название записи через `get_the_title()`.
   - Извлекает отрывок статьи через `get_the_excerpt()`.
   - Считывает дату публикации, автора и категорию.
   - Забирает произвольные поля `proficiency_level` и `required_tools`.
2. Генерирует в код страницы чистый `JSON-LD` блок `TechArticle`.
3. Вам **не нужно писать никакой код или разметку вручную** при добавлении новых статей!

## 🌐 6. Размещение файла `llms.txt` в корне домена

Для того чтобы ИИ-поисковики индексировали базу знаний вашего сайта:

1. Загрузите файл `llms.txt` в **самый корень вашего веб-сервера** (публичную папку `public_html` или `www`), чтобы он был доступен по адресу:
   `https://tochka-plavleniya.ru/llms.txt`

2. Настройка редиректа в `.htaccess` (если требуется):
```apache
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteRule ^llms\.txt$ /wp-content/themes/tochka-plavleniya/llms.txt [L]
</IfModule>
```

## 📋 7. Чек-лист финальной проверки после переноса

- [ ] Тема активирована в админке WordPress (`Внешний вид -> Темы -> Точка Плавления`).
- [ ] Перейдите в `Настройки -> Постоянные ссылки` и выберите вариант **«Название записи»** (`/%postname%/`).
- [ ] Создана страница с шаблоном **«Инструменты»** (`page-interactive.php`).
- [ ] Зайдите на любую статью и проверьте исходный код страницы (`Ctrl+U`) — в теге `<head>` должен присутствовать блок `<script type="application/ld+json">` с типом `"@type": "TechArticle"`.
- [ ] Проверьте URL `https://tochka-plavleniya.ru/llms.txt` в браузере.
