# Realization Project

Эта папка — единый пакет документации и технического задания по реализации сайта «Точка плавления».

## Структура пакета

- `01_SITE_STRUCTURE_AND_MENU.md` — информационная архитектура, 7 разделов верхнего меню, маршруты, правила адаптивности и UX.
- `02_INTERACTIVES_SPEC.md` — спецификация интерактивных инструментов (подбор температуры, выбор паяльника, диагностика брака, расход припоя, подбор флюса, медные трубы).
- `03_IMPLEMENTATION_ROADMAP.md` — пошаговый план внедрения, разбитый по этапам и приоритетам MVP.
- `04_DATA_SOURCES.md` — правила привязки к семантическому ядру, фактчекинг и риск-менеджмент.

## Исходные данные (Excel)

Канонические файлы семантического ядра находятся в корне репозитория:
- `../semantic_core.xlsx` — полное семантическое ядро проекта (~355 КБ).
- `../semantic_core_FULL_v3.xlsx` — структурированная версия ядра (~21 КБ).

Все интерактивные инструменты и темы статей опираются на эти файлы.
