# Интеграция шапки с Rank Math — этап 1

Дата: 2026-10-10. Источник темы: theme/.

## Исправления

- При поддержке WordPress title-tag ручной title больше не выводится: заголовок генерируется через wp_head и может управляться Rank Math.
- При определённой RANK_MATH_VERSION шапка не дублирует description, Open Graph и Twitter Card.
- Без Rank Math остаются существующие запасные description и социальные теги.
- У html один набор языковых атрибутов из language_attributes; вне WordPress используется lang=ru.
- Кодировка берётся из WordPress; подставляемые метаданные экранируются.
- Классы, стили, элементы поиска, переключения темы и навигационные ссылки сохранены.

## Границы изменений

Это не полный аудит SEO. extra_head, render_article_schema и render_rubric_schema пока не изменены. Поэтому отсутствие всех дублей Schema/canonical/robots ещё не подтверждено. Папки site2/, tchp/ и wp-content/ не синхронизированы этим пакетом.

Настройки базы, название сайта, главная страница, sitemap, SEO-поля записей, пользователи, индексация и URL не изменяются. Плагин Rank Math не включён в тему.

## Установка и откат

1. Сохранить копию текущих файлов темы на хостинге.
2. Убедиться, что активная тема соответствует корневой theme/, а не старому варианту.
3. Обновить includes/header.php в активной теме либо собрать и загрузить ZIP из актуальной theme/.
4. Очистить кеш, если используется.
5. Проверить исходный HTML главной, статьи и рубрики.
6. Для отката восстановить прежний includes/header.php.

## Проверки после установки

- С Rank Math: один title; нет ручных description/og/twitter из этой шапки; настройки title и description Rank Math видны в HTML.
- Без Rank Math на тестовой копии: один штатный title, запасные метатеги доступны.
- Один атрибут lang на html.
- Шапка, поиск и переключение темы внешне не изменились.
- Отдельно проверить extra_head и JSON-LD: этот этап их не исправляет.

Статус: код рассмотрен статически. PHP lint, запуск WordPress, браузерные проверки и развёртывание на хостинге не выполнены в этой сессии. Коммит не равен обновлению рабочего сайта.
