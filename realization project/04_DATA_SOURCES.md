# 04. Источники данных и семантическое ядро

## Связь с Excel-файлами проекта

В репозитории присутствуют два канонических файла семантики:
1. `semantic_core.xlsx` — полная база поисковых кластеров и интентов.
2. `semantic_core_FULL_v3.xlsx` — структурированная рабочая таблица с приоритетами.

## Классификация поисковых интентов
Все темы из семантического ядра распределяются по категориям реализации:
- **Информационный гайд (Guide):** статьи с пошаговыми фото/схемами («Как залудить жало паяльника»).\n- **Сравнение / Выбор (Selection):** статьи с таблицами параметров («Какой флюс выбрать для микросхем») + интеграция с интерактивным селектором.
- **Диагностика проблем (Troubleshooting):** статьи-разборы ошибок («Почему не плавится припой») + ссылка на диагностическое дерево.
- **Высокий риск (High Risk):** темы пайки аккумуляторов 18650, работы с сетевым напряжением 220 В, газовых горелок — требуют обязательных дисклеймеров по ТБ.

## Централизация технических констант
Для исключения разногласий между статьями и калькуляторами физические константы фиксируются в `site2/data/interactive-rules.php`:
- Температурные диапазоны ликвидуса и солидуса сплавов.
- Допустимые плотности тока и сечения монтажных проводов.
- Режимы отмывки различных типов флюсов.
