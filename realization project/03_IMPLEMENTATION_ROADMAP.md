# 03. План реализации (Roadmap)

## Приоритет MVP: «Эффективно, дешево, красиво»

### Этап 1: Архитектура навигации
1. Унифицировать массив пунктов в `site2/includes/header-nav.php`.
2. Подключить единое меню в `site2/includes/header.php`.
3. Реализовать адаптивное раскрывающееся меню для экранов шириной <900px.
4. Проверить корректность путей и отсутствие «битых» ссылок.

### Этап 2: Интерактивный хаб (`site2/interactive.php`)
1. Оформить страницу в виде каталога карточек инструментов.
2. Создать файл справочника правил и данных `site2/data/interactive-rules.php`.
3. Создать логические обработчики `site2/includes/interactive-functions.php`.
4. Реализовать клиентскую часть на Vanilla JS (без тяжелых сторонних фреймворков для максимальной скорости загрузки).
5. Запустить инструменты первой очереди: «Подбор температуры», «Выбор паяльника», «Мастер диагностики дефектов».

### Этап 3: Расширение интерактивов
1. Добавить калькулятор расхода припоя.
2. Добавить селектор флюса по металлу и типу работ.
3. Добавить специализированный мастер для пайки медных труб мягким/твердым припоем.

### Этап 4: Интеграция контента и перелинковка
1. Проставить ссылки из результатов интерактивов на целевые статьи блога.
2. Добавить карточки калькуляторов внутрь тематических статей (например, калькулятор температуры — в статьи о ПОС-61 и бессвинцовой пайке).
