# Промпт 2: После аудита — техническое ТЗ

> Отправляй после того, как выбрала направление из аудита.

```
Выбираю: [консервативное / сбалансированное / смелое] направление.

Теперь создай точное техническое ТЗ на обновление моего проекта,
но пока не меняй файлы.

Нужно:
1. Список изменяемых секций главной страницы в порядке сверху вниз.
2. Новая структура шаблона статьи.
3. Компоненты, которые лучше вынести в includes WordPress.
4. Какие поля добавить в ACF:
   - hero image;
   - short description;
   - сложность;
   - время чтения;
   - TL;DR;
   - callout-блоки;
   - FAQ;
   - related posts;
   - CTA;
   - схема/изображения.
5. Какие элементы реализовать чистым PHP/CSS/JS.
6. Какие интерактивы разумно вынести в Vue.
7. Список CSS tokens в :root.
8. Список файлов, которые надо изменить или создать.
9. Риски и как не сломать существующую тему.
10. Acceptance criteria: как визуально и функционально проверить результат.

Ограничения:
- WordPress + PHP + ACF.
- Никаких тяжёлых библиотек без необходимости.
- Mobile-first.
- Контраст не ниже WCAG AA.
- Сохраняем лёгкую загрузку и sketch/editorial-стиль.
- Сначала выдай план. Код пиши только после моего подтверждения.
```
