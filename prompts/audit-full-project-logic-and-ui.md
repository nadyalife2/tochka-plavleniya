ЖЁСТКИЕ ПРАВИЛА АУДИТОРА
═══════════════════════════════════════════════════
1. НИЧЕГО НЕ ВЫДУМЫВАЙ. Каждое утверждение опирается ТОЛЬКО на реальный код/данные.
2. НЕ ХВАЛИ РАДИ ВЕЖЛИВОСТИ. Похвала допустима только как «что работает» перед критикой.
3. КАЖДЫЙ ФАКТ — со ссылкой на файл:строка (например: seo/dashboard/dashboard.js:1240).
4. Разделяй: НАБЛЮДЕНИЕ (факт из кода) / ИНТЕРПРЕТАЦИЯ (почему это проблема) / РИСК (что сломается) / ФИКС (конкретное изменение).
5. Приоритеты: 🔴 БЛОКЕР (ломает работу/данные) → 🟠 ВЫСОКИЙ (серьёзная проблема) → 🟡 СРЕДНИЙ (ухудшает UX/надёжность) → 🔵 НИЗКИЙ (полировка).
6. НЕ ПРЕДЛАГАЙ «переписать всё с нуля» — только точечные, реализуемые правки, сохраняющие существующую архитектуру.
7. Игнорируй пробелы в форматировании и незначительные стилевые мелочи, если они не влияют на UX.
8. Если можешь — запусти `python tests/run-all-tests.py` и зафиксируй реальный результат. Если не можешь — честно напиши «не запускал».
9. Отвечай НА РУССКОМ, структурированно, с таблицами. Без воды и общих фраз типа «сделать современнее».

КОНТЕКСТ ПРОЕКТА (ФАКТЫ, проверь их в коде)
═══════════════════════════════════════════════════
- Название: «Точка Плавления» (tochka-plavleniya.ru) — русскоязычный инженерный медиа-портал и SEO-конвейер по пайке/электронике.
- GitHub-репозиторий: https://github.com/nadyalife2/tochka-plavleniya (origin в git; CI-раннер: .github/workflows/ci.yml, бейдж в README.md).
- Архитектура: локальный Python-конвейер (SEO-дашборд) + PHP-тема WordPress (публичный сайт).
- Ядро конвейера: seo/scripts/server.py (≈2 090 строк, HTTP-сервер с 30+ REST-эндпоинтами).
- UI дашборда: seo/dashboard/index.html (904 строки, 7 вкладок), dashboard.js (≈2 500 строк, 94 onclick-обработчика, 80 кнопок), dashboard.css (≈1 080 строк).
- База данных: SQLite seo/data/seo.db — 22 таблицы: 63 темы (topics), 46 конкурентов, 43 кластера, 100 ключей, 94 статьи конкурентов, 147 ссылок (links), 44 замера Вордстата, 17 замеров Мутагена, 6 фоновых задач, 30 запусков агентов.
- Публичный сайт: theme4/ — 2,38 МБ, index.php / article.php / interactive.php / category.php, router.php (красивые URL), 11 CSS-файлов (включая build.css — собранный Tailwind).
- Контракты данных: schemas/article-contract-v1.1.schema.json (+ v1), примеры article-example-v1.1.json.
- Тесты: tests/run-all-tests.py — 7 шагов, 43/43 PASS (JSON-схемы → PHP lint → mock-WordPress → Python unit → ссылки MD → SEO smoke → сборка zip с byte-parity).
- Редакционный стандарт: gem-knowledge/MASTER_EDITORIAL_BOOK.md (голоса Practico 1/2, триада «факт→механика→практика», запреты), AGENT_01/02/03.
- Скрипты конвейера (seo/scripts/, 31 шт.): wordstat.py, mutagen.py, keyword_suggestions.py, generate_brief.py, writer_practico.py, score_article.py, package_contract.py, linkgraph.py, priority_matrix.py, discover_competitors.py, bot_competitor_analyzer.py, run_pipeline.py и др.

A4. ВАЛИДАЦИЯ И КРАЙНИЕ СЛУЧАИ: пустые строки, null, некорректные id, повторные клики, конкурентные записи (два агента одновременно), таймауты внешних API (Мутаген/Вордстат), отказ сети.
A5. ДЕНЬГИ И ВНЕШНИЕ API: Мутаген списывает 0,30 ₽/фразу — проверь, что кэш реально работает, что повторная проверка не списывает, что баланс корректно отображается.
A6. БЕЗОПАСНОСТЬ: SQL-инъекции (f-строки в запросах), XSS (esc() везде ли?), хранение ключей (config/api-keys.local.yaml в .gitignore?), доступ к дашборду без пароля (сервер на 127.0.0.1 или открыт?).
