# Промпт 3: Аудит одного блока

> Используй когда хочешь улучшить конкретную секцию — hero, карточки, шаблон статьи и т.д.

```
Проведи аудит только блока [НАЗВАНИЕ БЛОКА] в моём текущем макете.

Проверь: цель блока, визуальную иерархию, типографику, отступы,
контраст, CTA, mobile 390 px, доступность и соответствие
sketch/editorial-стилю технического русскоязычного AI/DIY-блога.

Верни:
1. Что оставить.
2. 3–7 конкретных проблем.
3. Улучшенную структуру блока.
4. Точные размеры, отступы и состояния.
5. Текстовый wireframe.
6. Краткое ТЗ для WordPress/PHP/ACF.

Не пиши код и не предлагай Figma.
```

---

## Рекомендуемый порядок блоков для аудита

1. Hero (первый экран главной)
2. Лента статей (8–12 карточек)
3. Навигация и шапка
4. Шаблон статьи (TL;DR, оглавление, callouts, related)
5. Интерактивные блоки
6. Footer и CTA
