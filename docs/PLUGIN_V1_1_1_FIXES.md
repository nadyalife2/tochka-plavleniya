# tchp-content-fixed — плагин 1.1.1

Собран из `wp-content/plugins/tchp-content/tchp-content.php` (v1.1.0), оригинал не изменялся.
Архив: **`tchp-content-fixed.zip`** → внутри `tchp-content/tchp-content.php` (1 файл, 14,2 КБ).

## Что изменено

1. **Припой больше не навязывается.** В селекте появилась опция
   «— не применимо (статья не про конкретный сплав) —» (`value="none"`).
   При сохранении `none` поле удаляется, а не записывается как `pos61`.
   Для новых записей это значение по умолчанию.
2. **Температуры — только когда применимы.** Над полями появился чекбокс
   «Температурный режим применим к этой статье». Если снять — тип/диапазон/пик
   скрываются и удаляются при сохранении; снять галочку можно для статей про
   оборудование, химию, организацию места.
3. **Автоподстановка температур по сплаву.** Выбрали SAC305 → в пустые поля
   подставляются `310–350 °C` / `245 °C`; ПОС-61 → `260–295 °C` / `320 °C` и т.д.
   Заполненные вручную значения не перезаписываются; цифры можно править.
4. **Стандарт с пресетами.** Поле получило `datalist`: IPC-A-610G, J-STD-001,
   J-STD-020E, J-STD-004B, IPC-7095C, ГОСТ 21931-76, ГОСТ 21930-76,
   ANSI/ESD S20.20, IEC 61010-1. Можно вписать своё — поле осталось текстовым.
5. **Колонка «GEO» в списке записей.** Показывает `N/6` (припой, температуры,
   стандарт, источники, FAQ, ОТК) с подсказкой, что не заполнено:
   зелёный 6/6, оранжевый 3–5, красный 0–2.
   Для не-паяльных статей 4–5/6 — норма: температура и/или припой не применимы.
6. Версия `1.1.1` (шапка плагина и `TCHP_CONTENT_VERSION`).

## Как теперь создавать статью

1. Записи → Добавить новую → текст паттернами.
2. «Паспорт статьи»: припой (или «не применимо») → если выбрали сплав,
   чекбокс температур включится сам и цифры подставятся → проверьте/поправьте.
3. Стандарт — выберите из подсказки или впишите свой.
4. Оснастка, FAQ, источники — таблицами.
5. Сохранить → «Подтвердить проверку (ОТК)».
6. В списке записей смотрите колонку GEO: `6/6` — паспорт полный.

## Совместимость

- Работает с `theme4-fixed.zip`: тема не выводит припой/температуры в JSON-LD,
  если выбрано `none`/`universal` или поля пустые.
- REST-контракт не менялся: пайплайн (`delivery_cli.py`) по-прежнему передаёт
  канонические slug'и; изменения касаются только админского интерфейса.
- Метаданные существующих статей не мигрируют: у записей, сохранённых старой
  версией, припой мог записаться как `pos61` — для не-паяльных статей стоит
  открыть запись, выбрать «не применимо» и сохранить.

## Установка

1. Бэкап БД.
2. Плагины → Добавить новый → Загрузить плагин → `tchp-content-fixed.zip`
   (WordPress предложит заменить существующий — данные и настройки сохраняются).
3. Проверить, что версия 1.1.1, и открыть любую запись: под редактором —
   «Паспорт статьи» с новой опцией и чекбоксом.

## Проверка

- `php -l`: синтаксис чистый;
- структура архива: `tchp-content/tchp-content.php`;
- в коде: опция `none`, чекбокс `tchp_temp_applicable`, `datalist`, пресеты,
  колонка GEO, удаление метаполей при «не применимо».

Ограничение: живой WordPress локально не поднимался, поэтому UI-прогон
(чекбокс, автозаполнение) — сразу после установки на сайт.
