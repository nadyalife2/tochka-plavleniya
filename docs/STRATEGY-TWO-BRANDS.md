# Стратегия двух брендов: «Точка Плавления» + «Точка Ремонта»

> Коротко и по делу. Один движок, два бренда, сначала доход — потом масштаб.
> Этот файл — главный план. Детали: [`business-model-two-sites.md`](business-model-two-sites.md),
> [`unit-economics-two-sites.md`](unit-economics-two-sites.md),
> [`ROADMAP-TWO-SITES.md`](ROADMAP-TWO-SITES.md).
> Машинный контекст для маркетинговых скиллов: [`../.agents/product-marketing.md`](../.agents/product-marketing.md).

## 1. Главная идея

Мы строим **не два разных бизнеса, а один контент-движок**:

- одна тема WordPress, один плагин, один пайплайн, один дизайн-код;
- два бренда с разными аудиториями и обещаниями;
- доход — из услуг, PDF, партнёрки и B2B, а не из «рекламы потом».

**Формула:** проверенный регламент + калькулятор + понятный следующий шаг.

## 2. Два бренда

| | «Точка Плавления» (Practico) | «Точка Ремонта» |
|---|---|---|
| Кому | домашние мастера, начинающие, сервисные центры | собственники жилья, домашние мастера, бригады |
| Обещание | «паяй без перегрева и брака» | «ремонт без сюрпризов в смете» |
| Контент | пайка, сплавы, флюсы, дефекты, инструмент | смеси, плитка, стяжка, порядок работ, сметы |
| Деньги | консультации, PDF, B2B, партнёрка | PDF-сметы, лиды, партнёрка, B2B |
| Старт | уже есть | месяц 2–3 |
| Первый доход | 2–4 недели | 6–10 недель после запуска |

## 3. Один движок

| Слой | Что используем |
|---|---|
| Тема | `theme4` v4.0.0 |
| Плагин | `tchp-content` 1.1.1 |
| Контент | паспорт статьи, ОТК, JSON-LD/GEO |
| Пайплайн | `tools/delivery_cli.py`, генератор, схема v1 |
| Дизайн | Editorial Lab, жёлтый `#FFC700`, холст `#F6F6F6` |
| Аналитика | Яндекс.Метрика, Вебмастер, Search Console |
| Каналы | сайт, Telegram, VK, Rutube, Дзен, YouTube |

Новый сайт = новый бренд-слой + новая семантика, **не новый код**.

## 4. Что продаём

## 5. Воронка

```
Статья / видео
   ↓
Бесплатный калькулятор или чек-лист
   ↓
PDF / консультация / заявка
   ↓
Повторная покупка / B2B / лид
```

Правило: **на каждой странице один следующий шаг**, не пять.

## 6. Контент

| | Сайт №1 | Сайт №2 |
|---|---|---|
| Ритм | 2 статьи/нед | 1–1,5 статьи/нед |
| За 6 мес. | 30 новых + обновить 24 | 30 статей |
| Калькуляторы | 8 готовы, добавить 2–3 | 5 |
| Видео | 1 сессия/мес: 1 длинное + 5–8 shorts | 1 сессия/мес |
| Кластеры | сплавы, флюсы, инструмент, дефекты, BGA/SMD, старт | смеси, плитка, стяжка, штукатурка, гидроизоляция, сметы |

**Формат статьи:** TL;DR → паспорт → регламент → таблицы → FAQ → источники → CTA.

## 9. KPI и гейты

| Точка | Метрика | Решение |
|---|---|---|
| День 14 | 1–2 продажи/клиента | нет — менять оффер |
| День 30 | 5–15 тыс. ₽ | нет — усилить услуги/B2B |
| День 60 | 10–20 тыс. ₽, 5–8 статей №2 | продолжать |
| День 90 | 15–30 тыс. ₽, индексация ≥70% | масштабировать контент |
| День 180 | 30–60 тыс. ₽, 5 тыс.+ визитов №1 | решать про №3 |

**Стоп-факторы:** нет индексации → техаудит; нет продаж → оффер; нет трафика →
глубина/перелинковка; выгорание → 1 статья/нед.

## 11. Российская специфика

- **Налоги:** старт на НПД (4/6%), лимит 2,4 млн ₽/год; ИП/ООО — позже.
- **Данные:** 152-ФЗ, согласие на формы, политика конфиденциальности.
- **Реклама:** маркировка/ERID, `rel=sponsored`, без обещаний дохода.
- **YMYL:** рецензент, ГОСТ/СП/IPC, дисклеймеры.
- **Каналы:** Telegram, VK, Rutube, Дзен, Avito; YouTube — вторично.
- **Платежи:** ЮKassa/Boosty; не Stripe.
- **AI-поиск:** Яндекс Нейро + ChatGPT/Perplexity; `llms.txt`, JSON-LD.

## 12. Чего не делаем

- не запускаем третий сайт;
- не покупаем рекламу на трафик;
- не делаем курс до 50 продаж PDF;
- не покупаем 3D-принтер до 10+ итераций;
- не меняем ниши каждые две недели;
- не ставим community-скиллы без проверки.
