# Устройство: крепление, комплектующие, бюджетная сборка

> Инженерный черновик v1. Задача: снимать тепло с водяного радиатора отопления,
> вырабатывать им же электричество для обдува, крепиться без сверления и слива
> теплоносителя. Без аккумулятора и зарядки от сети.

## 1. Ограничения и требования

| Параметр | Значение |
|---|---|
| Типы радиаторов | чугунные секционные, алюминиевые, биметаллические |
| Температура поверхности | 50–80 °C (подача 70–90 °C) |
| ΔT «радиатор — воздух» | 30–55 °C |
| Крепление | без сверления, без слива, без инструмента, съёмное |
| Вес устройства | 200–400 г |
| Питание | только TEG, без батарей и сети |
| Безопасность | низковольтная цепь, изоляция, защита от перегрева |
| Бюджет v1 | 3–6 тыс. ₽ |

## 2. Морфологический анализ: варианты крепления

| Концепция | Как | Плюсы | Минусы | Цена |
|---|---|---|---|---|
| **A. Прижимная пластина + стяжки** | алюминиевая пластина 100×100×3 мм, 2 нейлоновые/стальные стяжки вокруг секций, силиконовые подкладки | универсально, регулируемое усилие, дёшево | стяжки могут тянуться от тепла; нужен доступ вокруг секции | 300–800 ₽ |
| **B. Магнитное** | 4–6 неодимовых магнитов (N42SH/SmCo) + стальная пластина + термопрокладка | мгновенная установка, без стяжек | работает только на стали/чугуне; алюминий/биметалл — нет; нагрев снижает силу | 600–1500 ₽ |
| **C. Крюк-подвес + рычаг** | крюк за верх радиатора, пружина/рычаг прижимает пластину | без стяжек, просто | устойчивость хуже, зависит от геометрии | 400–1000 ₽ |
| **D. Пружинные зажимы (струбцины)** | 2 зажима с силиконовыми губками за верх/низ секции | сильный прижим, съёмно | подходит не ко всем радиаторам; может мешать крану | 500–1200 ₽ |
| **E. Клей/скотч** | термостойкий клей/лента | просто | ползучесть, тепловое расширение, следы | 200–500 ₽ |

**Рекомендация v1:** **A + D** — алюминиевая пластина, два пружинных зажима с
силиконовыми губками (или стяжки), теплопроводящая прокладка. Это лучший баланс
«дёшево / универсально / сильный прижим / патентно отличимо».

### Схема (вид сбоку)

```
     радиатор (секция)
     ┌──────────────┐
     │  55–80 °C    │
     └──────┬───────┘
            │ термопрокладка 1.5–2 мм
     ┌──────┴───────┐
     │  TEG 40×40   │  ← прижим 0.3–1 кг/см²
     └──────┬───────┘
            │ термопрокладка
     ┌──────┴───────┐
     │  радиатор    │
     │  охлаждения  │
     │  + вентилятор│  ← 5 В, 40 мм
     └──────────────┘
```

## 3. Электрическая схема v1

```
TEG1 ── TEG2 ── TEG3   (последовательно, 3×40×40 мм)
        │
        ├── диод Шоттки (защита)
        ├── суперконденсатор 1 Ф / 5.5 В (буфер запуска)
        ├── DC-DC повышающий (LTC3108 или MT3608 + 3 TEG)
        ├── термостат KSD9700 45 °C (по желанию)
        └── вентилятор 40 мм, 5 В, 0.05–0.1 А
```

Логика: при нагреве радиатора TEG даёт напряжение → суперконденсатор копит энергию →
преобразователь запускает вентилятор. Нет тепла — нет питания, вентилятор стоит.
Аккумулятор не нужен.

**Варианты бюджета:**
- **Дешёвый:** 3 TEG последовательно (≈5–7 В при ΔT 50 °C) + MT3608 (старт от 2 В) +
  суперконденсатор 1 Ф. Цена ~1,5–2,5 тыс. ₽.
- **Надёжный:** LTC3108 (старт от 20 мВ) + 2 TEG + суперконденсатор. Цена ~2–4 тыс. ₽.

## 5. Сборка v1: пошагово

1. Вырезать алюминиевую пластину 100×100 мм, зачистить, обезжирить.
2. Наклеить термопрокладку на пластину; прижать TEG (2–3 шт.) последовательно.
3. Сверху — вторая прокладка и радиатор охлаждения; стянуть зажимами **без перекоса**.
4. Прикрутить вентилятор к радиатору (саморезы/стяжки), направить поток вдоль рёбер.
5. Собрать электрику: TEG → диод → суперконденсатор → DC-DC → вентилятор.
6. Поставить термостат (если нужен) в разрыв плюса.
7. Установить на радиатор: пластина к секции, зажимы за верх/низ, проверить прижим.
8. Замеры: температура радиатора, холодной стороны, напряжение/ток, старт вентилятора.

## 6. План испытаний

| Что | Чем | Критерий |
|---|---|---|
| T радиатора | ИК-термометр/термопара | 50–80 °C |
| ΔT | два датчика | ≥30 °C |
| Напряжение TEG | мультиметр | ≥3 В (3 модуля) |
| Ток/мощность | нагрузка/мультиметр | ≥0.3 Вт |
| Старт вентилятора | секундомер | ≤60 с после прогрева |
| Шум | субъективно/приложение | ≤30 дБ |
| Прижим | визуально/прокладка | равномерный отпечаток |
| Перегрев | 1 час работы | TEG ≤100 °C, пластик не плавится |

## 7. Что это даёт для патента

Кандидаты в отличительные признаки (проверить поиском):
- быстросъёмное крепление к секциям водяного радиатора с регулируемым прижимом;
- теплосъёмная пластина с компенсацией неровностей и защитой от перекоса;
- низкотемпературный запуск (ΔT 30–40 °C) с суперконденсатором;
- управление обдувом, исключающее переохлаждение радиатора;
- модульная установка 2–3 TEG.

## 9. Риски

- **Мало мощности при низком ΔT.** Решение: больше TEG, лучше тепловой контакт,
  низкопотребляемый вентилятор, суперконденсатор.
- **Переохлаждение радиатора.** Решение: термостат/ШИМ, отключение при снижении T.
- **Плохой прижим/перекос.** Решение: силиконовые губки, пружины, контроль отпечатка.
- **Пыль/конденсат.** Решение: фильтр, гидрофобная плата, дренаж.
- **Патентный риск.** Решение: патентный поиск, узкая формула, свои признаки.
