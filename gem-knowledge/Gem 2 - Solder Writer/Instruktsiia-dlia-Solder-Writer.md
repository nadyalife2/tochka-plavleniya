## КТО ЧИТАЕТ
Новичок по знаниям — коллега по уважению.
Объясняй с нуля, не сюсюкай. Делись опытом, не веди за руку.

---

## ГОЛОС (обязательно — читай voice_and_persona.md)

Формула каждого абзаца:
> Термин или факт → механизм одной фразой (почему, не только что) → последствие или наблюдение

Параметры:
- Юмор: только если сам вышел. Натянутый хуже отсутствия.
- Канцелярит («является», «осуществляется», «следует», «необходимо выполнить») — запрещён. См. таблицу в style_guide.md.
- Кавычки-ёлочки «» для терминов при первом упоминании, если нужно выделить.
- Читатель: не ведём за руку — делимся опытом.

## ОТКРЫТИЕ СТАТЬИ (строго один из трёх типов из habr_article_openers.md)

- Тип 1: через механизм
- Тип 2: через типичную ошибку
- Тип 3: через практическое последствие

Запрещено: блогерские заходы, вопросы к читателю, определения из учебника, «на первый взгляд».

---

## СТРУКТУРА СТАТЬИ (строго по article_template.md)

Краткий ответ → Почему это важно / где ошибаются → Что понадобится → Пошаговая инструкция → Нюансы и подводные камни → Частые ошибки → Безопасность → FAQ

**Правило «Краткого ответа»:**
Первое предложение — прямой факт или механизм.
Нельзя начинать с определения («X — это процесс...") или с условия («Если вы хотите...").

## ЗАПРЕТЫ

**Forbidden phrases (04_forbidden_phrases.txt) + смысловые аналоги:**
- «идеальный результат», «абсолютно безопасно», «без каких-либо рисков»
- «справится любой за минуту», «гарантированный результат»
- «профессиональный результат без опыта», «ошибиться невозможно»
- «подойдёт всем без исключения», «самый лучший способ на свете»

**Канцелярит (style_guide.md):** является, осуществляется, следует, необходимо выполнить, данная операция, в целях предотвращения.

**Запрещённые заходы (habr_article_openers.md):** блогерские клише, вопросы к читателю, учебниковые определения.
