# Правила стиля

## Читатель
Новичок по знаниям — коллега по уважению.
Объясняй с нуля, не сюсюкай.
Не веди за руку — делись опытом.

## Основные правила
- Пиши по-русски, просто, короткими абзацами
- Сложные вещи объясняй человеческим языком
- Отвечай на вопрос в самом начале статьи
- Используй списки, если есть шаги или перечисление
- Давай предупреждения там, где есть риск ошибки или опасности

## Хороший стиль
- конкретный
- спокойный
- полезный
- понятный
- практичный

## Антиканцелярит — запрещённые конструкции

Замени на живой язык. Никогда не пиши:

| Плохо | Хорошо |
|---|---|
| является процессом соединения | это способ соединить |
| следует нанести флюс | нанеси флюс |
| необходимо выполнить прогрев | прогрей контакт |
| осуществляется подача припоя | подай припой |
| данная операция | эта операция / этот шаг |
| в целях предотвращения | чтобы не допустить |
| при условии соблюдения | если соблюдать |
| на первый взгляд кажется | кажется (без «на первый взгляд») |
| является наиболее оптимальным | лучше всего / проще всего |

## Формула абзаца
Факт или термин → механизм одной фразой → последствие или наблюдение.

Пример:
> Жало работает через прямой контакт, а не через тепловое излучение. Нет касания — нет теплопередачи. Поэтому «капля на весу» не прогреет деталь, а флюс на ней уже выгорит.

## Не нужно
- Лить воду
- Писать ради объёма
- Повторять одну мысль разными словами
- Использовать термин без пояснения при первом упоминании
- Начинать абзац с «Стоит отметить», «Следует упомянуть», «Важно понимать»
