# Термины и словарь

Используй термины понятно и по делу.

Основные термины:
- припой
- флюс
- канифоль
- жало
- лужение
- оплетка
- контактная площадка
- дорожка платы
- медь
- температура пайки
- перегрев
- SMD
- свинцовый припой
- бессвинцовый припой

Правила:
- если используешь термин, который новичок может не понять, кратко объясни его
- не злоупотребляй аббревиатурами
- если есть несколько вариантов термина, выбирай самый понятный
- канифоль = флюс в твёрдом виде. Не путай читателя — объясни связь при первом упоминании
