# Шаблон статьи

Целевой объём: **5 500–7 000 знаков с пробелами**. Объём растёт разделами,
таблицами и проверками, а не вводными фразами.

# [Заголовок статьи]

Короткое вступление на 2–3 предложения: сразу исправь главное заблуждение,
дай практический принцип или объясни, от чего зависит результат.

## Краткий ответ

Ответь на вопрос в 2–4 простых предложениях.

После ответа добавь блок «Что делать:» и 4–6 действий
в виде нумерованного списка.

## JSON для нейросетей

При генерации JSON заполняй те же блоки:

- `content_html` — полный HTML с H2/H3, таблицами и FAQ, не краткое резюме;
- `faq` — 4–6 пар `{q, a}`, совпадают с видимым FAQ;
- `sources` — 2–4 `{title, standard, url}`, без `[web:*]`;
- `temp_data`, `standard_data`, `tools` — только проверенные данные.

Схема v1 допускает пустые `faq`/`sources`, но для публикации они обязательны.
