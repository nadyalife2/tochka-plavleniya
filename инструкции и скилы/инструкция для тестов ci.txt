Все написанные тесты, раннеры и полная конфигурация GitHub Actions CI/CD выложены в репозиторий (коммит ccbc772).

Теперь при каждой отправке кода на GitHub (git push или Pull Request) автоматически запускается облачный конвейер тестирования и сборки дистрибутивов.

Что настроено и выложено на GitHub
Конфигурация GitHub Actions CI: 

.github/workflows/ci.yml

Автоматически срабатывает на каждый push в ветку main и при открытии pull_request (а также доступен ручной запуск workflow_dispatch во вкладке Actions).
Разворачивает виртуальную машину ubuntu-latest с окружением PHP 8.2 и Python 3.11.
Устанавливает зависимости (pip install jsonschema).
Запускает мастер-тестер 

tests/run-all-tests.py
.
При успешном прохождении автоматически упаковывает и публикует свежие theme4.zip и tchp-content.zip во вкладке Actions → Artifacts (доступны для скачивания).
Интеграционный тестовый набор: 

tests/test-package-a1.php

Покрывает все 9 сценариев:
Отклонение пустых или пробельных q/a через REST API (400) без потери сохранённого FAQ.
Отклонение неизвестных припоев (400).
Сохранение пропущенных полей при частичных обновлениях (PATCH).
Защиту от рассинхронизации при подтверждении ревизии по expected_hash (409 Conflict).
Подтверждение актуальной версии (200 OK) и проверку всех 5 условий is_verified.
Автоматический сброс в in_review при модификации контента после проверки.
100% документную уникальность якорей и ID в DOM-дереве (включая разрешение конфликтов <section id="..."> и <h2 id="...">).
Нормализацию алиасов припоев (wood → vuda, rose → roze).
Корректную передачу владения SEO-разметкой Rank Math.
Кроссплатформенный мастер-раннер: 

tests/run-all-tests.py

Автоматически определяет путь к PHP: системный php в Linux/GitHub Actions либо портативный php.exe на Windows.
Прогоняет валидацию JSON-схем, PHP-линтинг, 34 интеграционных теста и валидацию ZIP-архивов.
Сборщик дистрибутивов: 

tools/build_distribution_archives.py

Упаковывает theme4.zip и tchp-content.zip с POSIX-путями (/) для корректной распаковки на Linux-хостингах.

Как запустить тесты локально перед пушем
В терминале из корня проекта достаточно выполнить одну команду:

bash
python tests/run-all-tests.py
Как наблюдать за тестами в GitHub
Перейдите в ваш репозиторий на GitHub: github.com/nadyalife2/tochka-plavleniya.
Откройте вкладку Actions.
Вы увидите запущенный workflow CI / Quality Gate.
После завершения (зеленая галочка):
Внизу страницы запуска в блоке Artifacts будут прикреплены собранные theme4.zip и tchp-content.zip.
Бейдж в корневом README.md покажет зелёный статус passing.
