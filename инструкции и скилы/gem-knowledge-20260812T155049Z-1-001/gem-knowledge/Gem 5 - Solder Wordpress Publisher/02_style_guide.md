# Правила стиля

Пиши по-русски.
Пиши просто.
Пиши короткими абзацами.
Сложные вещи объясняй человеческим языком.
Не используй канцелярит.
Не используй пустые вводные конструкции.
Не делай текст рекламным.
Не преувеличивай.
Не обещай идеальный результат.
Не пиши так, будто читатель уже профессионал.

Хороший стиль:
- конкретный
- спокойный
- полезный
- понятный
- практичный

Нужно:
- отвечать на вопрос в начале статьи
- использовать списки, если есть шаги
- разбивать статью на понятные блоки
- давать предупреждения там, где есть риск ошибки или опасности

Не нужно:
- лить воду
- писать ради объема
- повторять одну и ту же мысль разными словами
- использовать чрезмерно умные термины без пояснения
