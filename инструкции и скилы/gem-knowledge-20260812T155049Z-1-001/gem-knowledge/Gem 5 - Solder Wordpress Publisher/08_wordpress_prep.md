# Подготовка статьи к WordPress

Перед публикацией нужно подготовить:

- заголовок
- slug латиницей
- краткий excerpt
- рубрику
- теги

Правила:
- slug должен быть коротким и понятным
- заголовок не должен быть кликбейтным
- excerpt должен быть кратким и полезным
- рубрика должна быть одна основная
- теги только по делу

Перед публикацией проверить:
- понятен ли заголовок
- есть ли блок безопасности
- нет ли опасных советов
- нет ли воды
- нет ли фальшивых обещаний
- нет ли слишком спорных технических утверждений
